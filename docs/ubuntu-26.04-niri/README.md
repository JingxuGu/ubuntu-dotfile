# Ubuntu 26.04 与 Niri

这是 Ubuntu 26.04.1、Niri 26.04、DankMaterialShell 的实际配置快照。系统软件版本与显示器设置来自原机器，并不表示任意硬件已验证。

- [桌面与启动器](desktop.md)
- [终端与字体](terminal.md)
- [输入法](input-method.md)
- [截图](screenshots.md)
- [壁纸自动取色](wallpaper-colors.md)
- [软件包状态](packages.md)

原始数据位于 `dotfile/ubuntu-26.04-niri/`。恢复入口 `python3 dotfile/ubuntu-26.04-niri/restore.py` 默认预览；GNOME 专属设置不属于本方案。DMS 的动态配色输出在 chezmoi 中为 create-only 种子，后续仍由壁纸取色更新。
